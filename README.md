# Ironfield Vanguard

A hard 3D open-field defence game that runs in the browser. Drive your rover across the battlefield, deploy towers and troops where you stand, and hold your outposts against hostiles that come from every direction.

**Play:** https://pakwahng.github.io/ironfield/

## Features

- Ten-level campaign with a different map and twist on each level
- Endless mode with a saved best score
- Versus against an AI commander
- Fourteen structures and units, including shield generators, gunships and tanks that improve on higher levels
- Rover abilities: airstrike, repair pulse and EMP
- Interactive Boot Camp training, plus a Field manual for reference
- Keyboard, mouse and touch controls

## Running it

It is a single `index.html` file with no build step. Open it in a modern browser with an internet connection; the 3D engine (three.js r128) and fonts load from public CDNs.

Online versus play is only available in the claude.ai version, because it uses claude.ai's multiplayer service.

## Updating

Replace `index.html` with a new version and push. GitHub Pages republishes within a minute or two.
